# Laundry Services Hero Animation

## 📌 Project Description
This project is a responsive hero section for a laundry service website.  
It includes an animated image with orbit rotation and squeeze effect using CSS.

## 🚀 Features
- Hero section with heading and CTA button
- Smooth image animation (orbit + rotation + squeeze)
- Button hover effect
- Responsive design

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 📂 Folder Structure
project/
│── index.html  
│── style.css  
│── script.js  
│── README.md  

## ▶️ How to Run
1. Open index.html in browser
2. Ensure CSS is linked properly
3. Enjoy animation 🎉
